# Smart Contract Deployment

## Project
Blockchain-Based Event Ticket Verification

## Smart Contract
`EventTicketVerification.sol`

## Development Environment
- Remix IDE
- Solidity
- Ethereum-compatible development environment

## Deployment Steps
1. Open the Solidity contract in Remix IDE.
2. Select the Solidity compiler version compatible with the contract.
3. Compile `EventTicketVerification.sol`.
4. Open the Deploy & Run Transactions panel.
5. Select the appropriate execution environment and deploy the contract.
6. Confirm the deployment transaction.
7. Verify that the deployed contract appears under Deployed Contracts.

## Initial Testing
The `createEvent` function was tested in Remix, and the transaction completed successfully.

## Important Notes
- The contract was deployed for educational and testing purposes.
- The deployment network and contract address should be recorded when available.
- Never share private keys or seed phrases in this repository.
- Test all ticket-related functions before using the contract in a real event.
